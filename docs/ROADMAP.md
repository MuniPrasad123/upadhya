# Roadmap

## Foundation

Establish isolated local infrastructure, schema migrations, health visibility, validated textbook upload, and automated tests.

## Curriculum grounding

Extract page-level text, preserve page references, define chunking and indexing, connect Qdrant, and build a citation evaluation set before adding generated answers.

## Learning experience

Add guarded tutoring, curriculum-aligned assessments, teacher-reviewed explanations, multilingual delivery, and a Flutter client.

## Personalization and modalities

Introduce consent-based local learner memory, voice and visual learning, and carefully scoped agents and MCP tools. Each capability requires privacy and safety review plus measurable learning-quality gates.
